# استخاره با قرآن

وب‌اپلیکیشن انتخاب صفحه قرآن و نمایش آیه آغازین آن.

## ویژگی‌ها
- انتخاب صفحه با رابط گرافیکی
- نمایش خودکار نتیجه پس از رهاکردن نشانگر
- خواندن اطلاعات قرآن از فایل محلی
- پیاده‌سازی با Python و HTML

## فایل‌های اصلی
- `app.py`: سرور برنامه
- `index.html`: رابط کاربری
- `quran_pages.json`: اطلاعات صفحات قرآن
- `build_quran_data.py`: اسکریپت ساخت اطلاعات صفحات
